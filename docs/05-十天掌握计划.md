# 10 天掌握计划

你还有一个 Agent 项目要作为简历核心，因此后端项目应控制投入：目标是能跑、能画、能解释失败场景，而不是继续堆功能。

| 天 | 学习任务 | 当天产物 |
|---|---|---|
| 1 | 跑 `smoke-test.ps1`，跟踪一笔直接预约 | 手画请求时序图 |
| 2 | 精读三个预约 Lua 脚本 | 口述三个 Redis Key 的含义 |
| 3 | 精读 `createOrder` 和唯一索引 | 写出五个业务不变量 |
| 4 | 精读 `releaseOrPromote` | 手画订单/候补双状态机 |
| 5 | 模拟 MQ 重复、Redis 补偿延迟 | 写失败矩阵 |
| 6 | 阅读多级缓存和 afterCommit 驱逐 | 解释穿透、击穿、雪崩 |
| 7 | 阅读订阅 Feed、点赞 ZSet、签到 Bitmap | 各准备一个 30 秒回答 |
| 8 | 不看文档讲 3 分钟项目 | 录音并删掉含糊词 |
| 9 | 从空环境部署并跑验收 | 保存终端结果 |
| 10 | 按追问清单模拟面试 | 形成一页速查表 |

## 每天 90 分钟分配

- 35 分钟读主链路代码。
- 25 分钟做一个可观察实验。
- 20 分钟脱稿复述。
- 10 分钟记录仍然答不清的问题。

## 与 Agent 项目的时间分配

建议把 65%～70% 的项目时间留给 Agent 核心项目，CityPass 占 30%～35%。CityPass 的价值是证明你有 Java 工程基础、并发一致性意识和中间件经验。做到能解释设计取舍和故障恢复后，就应把时间转回 Agent 项目与算法/Java 基础复习。
